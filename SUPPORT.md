# Support

[Open an issue](https://github.com/round/anew.page/issues) with a question, a bug, or a page that will not encode. Include the URL
you were given, or the HTML you were trying to publish, and what you expected to happen. There is no
support address to write to: anew holds no account and no data on your behalf, so there is nothing a
private channel would be needed to discuss.

anew.page is maintained by one person, so replies are not instant, but every issue is read. There is
no account to recover and no data to delete — a page lives in its URL, so nothing is held for you.

Report a security issue the same way, and label it `security`. Describe the shape of the finding
rather than posting a working exploit, and please do not test against pages you did not author.

Reference documentation is in [DOCS.md](DOCS.md); the machine-readable specification is at
[llms.txt](https://anew.page/llms.txt).
